# Parsa Emami · پارسا امامی

**Software Engineer · Security Architect**

I build Laravel web systems and open-source security tools, with a focus on application architecture, authorization boundaries and verifiable releases.

[Official website — Parsa Emami](https://parsaaemm.dev/) · [LinkedIn — Parsa Emami](https://www.linkedin.com/in/parsaaemm/) · [GitHub — Parsa-Emami](https://github.com/Parsa-Emami) · [Résumé](https://parsaaemm.dev/resume/) · [Email](mailto:parsa.emm@gmail.com)

Based in Babol, Iran. Open to international roles, relocation & selected collaborations.

## Selected engineering work

- **[Attestara](https://github.com/Parsa-Emami/Attestara)** — A local release-evidence CLI that checks manifests, file bytes and SBOMs, evaluates the evidence-presence rule, and assesses signatures against independently configured trust. [Project notes](https://parsaaemm.dev/projects/attestara/)
- **[RiskWeft](https://github.com/Parsa-Emami/Riskweft)** — A local-first web foundation with a roadmap browser and bounded JSON structure preview. The complete model-to-threat workflow is still being developed. [Project notes](https://parsaaemm.dev/projects/riskweft/)
- **[MirageMesh](https://github.com/Parsa-Emami/Miragemesh)** — A local-first security application with a supervised Go engine, isolated decoys, durable offline event spooling and a browser interface for incident replay and triage. [Project notes](https://github.com/Parsa-Emami/Miragemesh#full-product-endpoint)
