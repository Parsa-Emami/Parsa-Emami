# Parsa Emami · پارسا امامی

**Software Engineer · Security Architect**

I build Laravel backend systems and local-first open-source security tools. My work emphasizes verifiable releases, authorization boundaries and reproducible engineering.

[Official website — Parsa Emami](https://parsaaemm.dev/) · [LinkedIn — Parsa Emami](https://www.linkedin.com/in/parsaaemm/) · [GitHub — Parsa-Emami](https://github.com/Parsa-Emami) · [Résumé](https://parsaaemm.dev/resume/) · [Email](mailto:parsa.emm@gmail.com)

Based in Babol, Iran. Open to English-speaking software and application-security roles, with the Netherlands as a preferred relocation destination; remote, hybrid and on-site considered.

## Selected engineering work

- **[Attestara](https://github.com/Parsa-Emami/Attestara)** — *Local CLI + browser viewer*. A local release-evidence CLI that checks manifests, file bytes and SBOMs, evaluates the evidence-presence rule, and assesses signatures against independently configured trust. [Technical evidence](https://parsaaemm.dev/projects/attestara/)
- **[KeyHelix](https://github.com/Parsa-Emami/Keyhelix)** — *Local-first workspace · Linux v1 release*. Offline-first secrets and authorization workspace with scoped access, audited reveals and key rotation. The published release targets Linux x86_64. [Technical evidence](https://github.com/Parsa-Emami/Keyhelix/blob/main/docs/release/USER_GUIDE.md)
- **[MirageMesh](https://github.com/Parsa-Emami/Miragemesh)** — *Local workflow · v1 gate pending*. A local-first security application with a supervised Go engine, isolated decoys, durable offline event spooling and a browser interface for incident replay and triage. [Technical evidence](https://github.com/Parsa-Emami/Miragemesh#full-product-endpoint)
- **[BreachAtlas](https://github.com/Parsa-Emami/Breachatlas)** — *Local DFIR workspace · independent offline verifier*. Seals evidence with SHA-256, records custody, builds timelines and exports portable bundles for independent offline verification. [Technical evidence](https://github.com/Parsa-Emami/Breachatlas/blob/main/docs/release/USER_GUIDE.md)
- **[Demian](https://github.com/Parsa-Emami/Demian)** — *Seven single-player games · production acceptance pending*. A café-themed 2D game suite with asynchronous weekly competition and a Laravel backend. Mobile, hosting and character-art acceptance remain separate gates. [Technical evidence](https://github.com/Parsa-Emami/Demian/blob/main/README.fa.md)
- **[RiskWeft](https://github.com/Parsa-Emami/Riskweft)** — *Web foundation · in development*. A local-first web foundation with a roadmap browser and bounded JSON structure preview. The complete model-to-threat workflow is still being developed. [Technical evidence](https://parsaaemm.dev/projects/riskweft/)

### Engineering focus

- **Backend & full-stack:** Laravel/PHP, Go and JavaScript; APIs, testing and maintainable delivery.
- **Security engineering:** authorization boundaries, secret lifecycle, incident evidence and supply-chain verification.
- **Evidence first:** documented scope, reproducible checks and clearly identified release limits.
