# Search identity architecture

The canonical public identity is **https://parsaaemm.dev/**. GitHub, LinkedIn, the GitHub profile README, and the generated GitHub Pages mirror should all reinforce that same entity.

## Design rules

- `data/profile.json` is the source of truth for identity content.
- The visible text block at the top of `README.md` is intentional; do not move all identity text back into SVG cards.
- The GitHub Pages site is a secondary mirror. It is generated with `noindex,follow` and points its canonical metadata at `https://parsaaemm.dev/` so it does not compete with the primary website.
- Keep `Parsa Emami`, `Parsa-Emami`, `parsaaemm`, and `پارسا امامی` consistent across public profiles.
- Public repository READMEs should link back to `https://parsaaemm.dev/` when contextually useful.

## Manual account setting

GitHub profile settings are not generated by this repository. Set the public **Website** field on the GitHub account to:

`https://parsaaemm.dev/`

After deploying the primary website, submit its sitemap in Google Search Console and inspect the homepage plus the main profile/content URLs.
